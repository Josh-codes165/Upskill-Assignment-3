# Personal Portfolio Website

A responsive personal portfolio website built with **HTML5** and **CSS3** as part of a CSS Introduction and Box Model assignment.

## Overview

This project showcases my profile, technical skills, projects, and contact information while demonstrating core CSS concepts such as selectors, text styling, positioning, the box model, hover effects, and Flexbox.

## Features

### Navigation Bar

* Fixed navigation bar positioned at the top of the page.
* Smooth and clean layout for easy navigation.

### Header Section

* Full name display.
* Professional tagline.
* Social media link for networking.

### About Me Section

* Profile image.
* Short biography.
* Side-by-side layout using Flexbox.

### Skills Section

* Displays six technical skills.
* Built using Flexbox for responsive alignment.

### Projects Section

* Three project cards.
* Each card contains:

  * Project image
  * Project title
  * Project description
  * "View Project" button

### Contact Section

* Email address.
* Links to social media platforms.
* Easy ways for visitors to connect.
